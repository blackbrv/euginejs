## Saving

<Callout type="warn">
  Prefer `editor.save()` over `editor.storage.save(editor.serialize())`. It attaches the revision
  the document was based on, which is what lets an adapter reject a stale overwrite. Forgetting it
  is what makes two people editing one page silently last-write-wins.
</Callout>

<CodeFromFile file="save-and-load" region="save" title="A save that can be rejected" />

`SaveResult` is a discriminated union, so the conflict branch is not optional:

```ts
type SaveResult =
  | { ok: true; revision?: number }
  | { ok: false; reason: "conflict"; current?: SerializedDocument };
```
